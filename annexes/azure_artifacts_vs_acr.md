# Azure Artifacts vs Azure Container Registry

| Besoin | Service recommandé |
|---|---|
| Image Docker | Azure Container Registry |
| Package npm privé | Azure Artifacts |
| Package NuGet privé | Azure Artifacts |
| Package Maven privé | Azure Artifacts |
| CLI distribuée en npm | Azure Artifacts |
| API conteneurisée à déployer | Azure Container Registry |
| Dépendances publiques Angular/npm via feed contrôlé | Azure Artifacts avec upstream sources |

ACR est le registry de conteneurs.

Azure Artifacts est le gestionnaire de packages.
