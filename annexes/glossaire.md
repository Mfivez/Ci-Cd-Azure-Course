# Glossaire

| Terme | Définition |
|---|---|
| Agent | Machine qui exécute les étapes du pipeline. |
| ACR | Azure Container Registry, registry d’images Docker dans Azure. |
| App Service | Service Azure qui héberge une application web ou un conteneur. |
| App Service Plan | Capacité d’hébergement utilisée par App Service. |
| Artifact | Résultat livrable d’un build. En Docker-first, l’artefact principal est l’image Docker. |
| Azure Artifacts | Service Azure DevOps pour packages npm, NuGet, Maven, Python, Cargo, Universal Packages. |
| Azure Pipelines | Service Azure DevOps qui automatise CI/CD. |
| CD | Livraison ou déploiement continu. |
| CI | Intégration continue. |
| Container Registry | Entrepôt d’images Docker. |
| Deployment Slot | Emplacement parallèle d’un App Service, par exemple staging. |
| Dockerfile | Recette de construction d’une image Docker. |
| Environment Azure DevOps | Objet de déploiement utilisé pour l’historique, approvals et checks. |
| IaC | Infrastructure as Code. |
| Service Connection | Connexion sécurisée utilisée par un pipeline pour accéder à Azure, ACR ou autre service. |
| Smoke test | Test rapide qui vérifie que l’application démarre et répond. |
| Variable Group | Groupe de variables réutilisables dans Azure Pipelines. |
