# Glossaire

| Terme | Définition |
|---|---|
| Agent | Machine qui exécute les étapes d’un pipeline |
| App Service | Service Azure permettant d’héberger une application web |
| Approbation | Validation humaine demandée avant de continuer un déploiement |
| Artefact | Résultat produit par un build et réutilisable par un déploiement |
| Build | Étape qui prépare une version exploitable de l’application |
| CI | Intégration continue : vérification automatique du code |
| CD | Livraison ou déploiement continu : mise à disposition d’une version validée |
| Deployment slot | Emplacement parallèle d’un Azure App Service, par exemple staging |
| Environment | Cible de déploiement dans Azure DevOps |
| Pipeline | Suite automatisée d’étapes de build, test ou déploiement |
| Pull request | Demande d’intégration d’une branche dans une autre |
| Secret | Valeur sensible qui ne doit pas être visible dans le code ou les logs |
| Service Connection | Connexion sécurisée entre Azure DevOps et un service externe |
| Smoke test | Test rapide vérifiant que l’application répond après déploiement |
| Stage | Grande phase d’un pipeline YAML |
| Swap | Échange entre deux slots App Service |
| Variable Group | Groupe de variables réutilisables dans Azure Pipelines |
