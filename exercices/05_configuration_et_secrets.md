# Exercice 5 — Classer configuration et secrets

Classer les valeurs suivantes dans une des catégories :

```text
YAML
Variable Group
Key Vault
Service Connection
Application Settings
```

Valeurs :

1. `imageRepository=croissant-api`
2. `APP_SERVICE_NAME=croissant-api-prod`
3. `DATABASE_PASSWORD=...`
4. `ENVIRONMENT_NAME=production`
5. Connexion permettant au pipeline de déployer dans Azure
6. Connexion permettant au pipeline de pousser dans ACR
7. `WEBSITES_PORT=8080`
8. `LOG_LEVEL=debug`
